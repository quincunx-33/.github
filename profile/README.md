## About Quincunx-33

Quincunx-33 is an independent developer organization focused on building practical, experimental, and privacy-conscious software for the modern web. We explore the intersection of full-stack development, artificial intelligence, cybersecurity research, browser technologies, and performance engineering.

> **Code with curiosity. Build with purpose. Learn in public.**

## What we build

- **Web applications** — fast, accessible, and responsive browser experiences.
- **Developer tools** — lightweight utilities that improve testing, debugging, and workflows.
- **AI and safety research** — educational experiments and authorized red-team analysis.
- **Systems and WebAssembly** — browser-based emulators, performance tools, and low-level experiments.
- **Privacy-focused utilities** — practical tools designed with user control and transparency in mind.

## Featured projects

| Project | Description | Main technologies |
|:--|:--|:--|
| [Ai-jailbreak](https://github.com/Quincunx33/Ai-jailbreak) | Prompt collection and exploit-technique research for authorized AI red-teaming and safety work. | JavaScript, AI Safety |
| [Virtual-machine](https://github.com/Quincunx33/Virtual-machine) | A browser-based emulator for booting a classic 32-bit operating system. | JavaScript, WebAssembly |
| [Stress-Tester](https://github.com/Quincunx33/Stress-Tester) | Cluster-driven HTTP load generation, benchmarking, and WAF auditing for authorized environments. | TypeScript, HTTP |
| [StressTest-wasm](https://github.com/Quincunx33/StressTest-wasm) | WebAssembly-based stress testing and performance benchmarking. | Rust, WebAssembly |
| [image-forensics](https://github.com/Quincunx33/image-forensics) | Privacy-first in-browser image forensics with ELA, FFT, DCT, noise, and copy-move analysis. | TypeScript, Rust, WebAssembly |
| [hostOnion](https://github.com/Quincunx33/hostOnion) | Host PHP sites as Tor v3 onion services with health checks and hardened runtime controls. | Python, Tor |

## Development principles

- Build small, useful, and maintainable tools.
- Prefer clear documentation and reproducible workflows.
- Treat security research as responsible, authorized, and defensive work.
- Respect privacy, user consent, and platform policies.
- Keep learning, experimenting, and sharing improvements.
